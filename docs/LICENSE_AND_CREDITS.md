# Licença e Créditos (CleanFrame)

## Resumo

O **CleanFrame** é um trabalho derivado e adaptado focado exclusivamente em:

- Tema claro (light-only) de alta legibilidade
- Coerência visual e previsibilidade de contraste
- Eliminação de color leaks em seleções, menus, inputs e popups
- Pipeline de normalização GTK4 CSS para GNOME 40-49
- Integrações práticas para aplicações do ecossistema (Qt, Flatpak, Snap, Electron, LibreOffice Calc, FileZilla)

Consulte o arquivo canonico de creditos na raiz: [CREDITS.md](../CREDITS.md).
